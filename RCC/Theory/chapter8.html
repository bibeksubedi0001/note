8.2 Interaction Diagrams for Columns 2080

PAST EXAM QUESTIONS:

  1. Define the interaction diagram with its features and sketches. Discuss the failure modes in eccentric compression within the interaction diagram. [6] (2080 Bhadra, Q3a)

A column carries an axial load P together with a moment M = P·e. The interaction diagram is the failure envelope plotting every (Pu, Mu) pair the section can just resist; any point inside is safe, on the curve is at failure, outside is unsafe.

Key features:

  • Top (Puz, pure axial): the maximum squash load, M = 0.
  • Balanced point: concrete crushing (0.0035) and steel yielding occur together — the maximum moment capacity.
  • Bottom (pure moment): P = 0, the section acts as a beam.
  • Above the balanced point → compression-controlled (brittle) failure — adding axial load reduces the moment capacity; below → tension-controlled (ductile) failure — adding axial load increases the moment capacity.

Design method (SP-16 biaxial)

  1. Squash load: Puz = 0.45fckAc + 0.75fyAsc (assume a steel ratio p = 0.8–4%, Asc = p·bD100).
  2. Uniaxial capacities Mux1, Muy1 for the given PufckbD and d′D from the SP-16 interaction charts.
  3. Exponent αn = 1.0 at PuPuz = 0.2 → 2.0 at 0.8 (linear between).
  4. Biaxial check: (MuxMux1)αn + (MuyMuy1)αn ≤ 1.0 — if not, increase steel or size.
  5. Provide lateral ties: φtie ≥ ¼φmain (≥ 6 mm), spacing ≤ least of 16φmain, b, 300 mm.

Sample: 400×400, Pu 800, e 80 ⇒ M = 64 kN-m each way; with p = 0.8% (Asc 1280), Puz = 1827 kN, Pu/Puz = 0.44, αn = 1.40, Mu1 ≈ 109 ⇒ 2(64/109)1.4 = 0.95 ≤ 1 ⇒ safe, 8−16 mm φ.

PAST EXAM QUESTIONS:

  1. Column 650×450, factored 1600 kN; moments 90/55 (top), 35/30 (bottom); eff lengths 7 & 6.5 m; double curvature. M30/Fe500 TMT. Drawings. [12] (2082 Bhadra, Q4a)
  2. Slender column 400×500, Lex 7.0, Ley 6.0; factored 1600 kN; top Mux 180, Muy 110; single curvature. M20/Fe415. [12] (2081 Bhadra, Q4b)
  3. Braced column 450×350, clear 4.0 m, axial 700 kN, BM 100 (major) & 80 (minor). M25/Fe415. [12] (2080 Bhadra, Q3b)
  4. Unbraced column 400×350, clear 6.0 m, axial 600 kN, BM 100 (major) & 50 (minor). M20/Fe415. [14] (2079 Bhadra, Q3b)
  5. Design steps for a RC long column of an unbraced frame. [10] (2065 Kartik, Q5b)

A column is slender if the slenderness ratio leD > 12 (braced) about either axis (le = effective length = k·l0, k from IS 456 Table 28 depending on the end restraints and whether the frame is braced). Slender columns fail by buckling, so an additional moment from the P-Δ effect is added:

Max = Pu·D2000(lexD)²   (× a reduction factor k = Puz − PuPuz − Pbal ≤ 1)

The column is then designed for the total moment Mu = initial moment (including the minimum eccentricity moment) + Ma, using the same SP-16 biaxial procedure as a short column.

8.5 Reinforcement Detailing / Capacity Check 2065

PAST EXAM QUESTIONS:

  1. Column 600×400 with 8−28 mm, Mux 350, Muy 50, Pu 2000. Check safety. M20/Fe415, cover 60. [10] (2065 Kartik, Q1b)

To check an existing column: compute Puz from the provided steel, read Mux1 and Muy1 from SP-16 for the actual PufckbD, find αn from PuPuz, then verify (MuxMux1)αn + (MuyMuy1)αn ≤ 1.0. Detailing: longitudinal steel 0.8–6% of the gross area (≥ 4 bars, ≥ 12 mm), lateral ties as in 8.3, and for earthquake resistance special confining hoops over a length l0 at each end (see Ch 11).
