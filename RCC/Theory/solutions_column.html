1.  Define the interaction diagram with its features and sketches. Discuss the failure modes in eccentric compression within the interaction diagram. 2080 Bhadra · Q3a [6 marks]

The P–M interaction diagram is the locus of all combinations of axial load Pu and moment Mu that cause a given column section to just reach its ultimate strength. Any (Pu, Mu) point inside the curve is safe; a point on or outside it means failure.

Key points: Puz (pure axial, top), Mu (pure bending, bottom), and the balanced point (Pb, Mb) where the concrete reaches 0.0035 as the tension steel yields. Above the balanced point the failure is by compression (concrete crushes, small eccentricity — brittle); below it the failure is by tension (steel yields first, large eccentricity — more ductile). Note that adding moment actually reduces the axial capacity above the balanced point and increases it slightly below.

P–M interaction diagram: the envelope of safe (Pu, Mu) combinations, with the balanced point dividing compression-controlled from tension-controlled failure.
Pu = 0.4fckAc + 0.67fyAsc
e.g. 400×500 with 1% steel, M25/Fe500: Asc = 2000 mm² → Pu = 2650 kN, Puz = 0.45fckAc + 0.75fyAsc = 2977 kN.
300×400 with 2%, M20/Fe500: Asc = 2400 → Pu = 1745 kN, Puz = 1958 kN.

Minimum eccentricity emin = l500 + D30 ≥ 20 mm; if actual e ≤ 0.05D the column is designed as axially loaded.

Typical biaxially-loaded column: longitudinal bars distributed on all four faces, enclosed by lateral ties.
1. Factored Pu, Mux, Muy (add minimum eccentricity moments).
2. Assume steel p = 100AscbD and d′D; compute PufckbD, MufckbD².
3. From the SP-16 chart read the uniaxial capacities Mux1, Muy1 for that Pu.
4. Puz = 0.45fckAc + 0.75fyAsc; αn = 1.0 at PuPuz = 0.2, = 2.0 at 0.8 (linear between).
5. Check (MuxMux1)αn + (MuyMuy1)αn ≤ 1.0. Increase steel and repeat if not satisfied; detail longitudinal bars (0.8–6%) and ties.

2.  Design a short column 400×500 mm, unsupported length 4.0 m, both ends held and restrained against rotation at one end, carrying a factored axial load of 1600 kN with factored moments of 150 kN-m and 50 kN-m about the two axes. Use M25 and Fe500. 2080 Baishakh · Q2b [10 marks]

Try p = 2% → Asc = 4000 mm². Puz = 0.45×25×(200000−4000) + 0.75×500×4000 = 2205 + 1500 = 3705 kN; PuPuz = 0.43 → αn = 1.39.

PufckbD = 1600×10³25×400×500 = 0.32; d′D = 0.1. From SP-16: Mux1fckbD² ≈ 0.15 → Mux1 ≈ 375 kN-m; Muy1 (about minor, b=400) ≈ 0.15×25×500×400² = 300 kN-m.

Check: (150375)1.39 + (50300)1.39 = 0.28 + 0.08 = 0.36 ≤ 1.0 ⇒ safe (2% could even be reduced). Provide 8−25 mm with ties.

Each: assume steel p, Asc=p·bD100 → Puz=0.45fckAc+0.75fyAsc → αn (1.0 at PuPuz=0.2, 2.0 at 0.8) → read Mux1, Muy1 from SP-16 (d′D=0.1) → check (MuxMux1)αn+(MuyMuy1)αn≤1.

4.  Design a column 350×350 mm carrying a factored axial load of 1440 kN with Mux 195 and Muy 180 kN-m; unsupported 3.50 m. Use M20 and Fe500 (TMT) and provide ductile detailing of the transverse reinforcement. 2076 Chaitra · Q2b [12 marks]
