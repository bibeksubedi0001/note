2.1 INTRODUCTION & TYPES OF BEAM

A beam is a member primarily subjected to flexure (bending); it supports the loads applied by slabs and its own weight through internal moments and shears.

  • Singly-reinforced beam: reinforcement only in the tension zone.
  • Doubly-reinforced beam: reinforcement in both tension and compression zones (used when the section size is limited).
  • T-/L-beams (flanged / spandrel beams): a portion of the slab acts with the beam in resisting compression at mid-span — T at an interior beam, L at an edge beam. At supports (negative moment) the flange is in tension, so they are designed as rectangular beams.

Two problems arise: analysis (geometry and steel known → find capacity) and design (loads known → find depth, width and steel).

2.2 ASSUMPTIONS IN FLEXURE (IS 456:2000, CL. 38.1)

  1. Plane sections normal to the axis remain plane after bending (strain varies linearly across the depth).
  2. Maximum strain in concrete at the outermost compression fibre = 0.0035.
  3. The design compressive stress of concrete = 0.67fckγm = 0.671.5 · fck = 0.446fck (≈ 0.45fck).
  4. The tensile strength of concrete is ignored.
  5. Design stress in steel is limited to fy1.15 = 0.87fy.
  6. The maximum strain in tension steel at failure ≥ 0.87fyEs + 0.002.

2.3 STRESS BLOCK PARAMETERS

Figure 2.1: Section, strain diagram and rectangular-parabolic stress block

The compressive stress block is parabolic over 47·xu and constant (0.446fck) over 37·xu. This gives:

  • Total compressive force C = 0.36fck·b·xu (average stress 0.36fck).
  • Centroid of compression at 0.42xu from the extreme compression fibre.
  • Lever arm Z = d − 0.42xu.

  • Balanced (xu = xu,max): steel yields as concrete crushes.
  • Under-reinforced (xu < xu,max): steel yields first → ductile failure with warning (preferred by IS 456).
  • Over-reinforced (xu > xu,max): concrete crushes first → brittle failure, avoided.

2.5 ANALYSIS OF SINGLY-REINFORCED BEAMS

Steps: (I) find Ast; (II) depth of NA from C = T: 0.36fckbxu = 0.87fyAst → xu = 0.87fyAst0.36fckb; (III) xu,max; (IV) compare; (V) MOR.

Moment of resistance:
Under-reinforced / balanced: Mu = 0.87fyAst·d[1 − Astfybd·fck]
Over-reinforced: Mu = Mu,lim = 0.36fckb·xu,max(d − 0.42xu,max)
Example 2.1 — MOR of a singly-reinforced beam

b = 250, d = 360 mm, M20, Fe415, 3−16 mm φ bars.

Ast = 3×(π4)×16² = 602.88 mm².

xu = 0.87×415×602.880.36×20×250 = 120.93 mm.

xu,max = 0.48×360 = 172.8 mm → xu < xu,max ⇒ under-reinforced.

Mu = 0.87×415×602.88×360×[1 − 602.88250×360×41520] = 67.47 kN-m.

Over-reinforced sections need the strain-compatibility method to find the steel stress fst: assume xu → εst = 0.0035(dxu − 1) → read fst from SP-16 (Table A) → check C = T (0.36fckbxu = fstAst).

2.6 DESIGN OF SINGLY-REINFORCED BEAMS

  1. Compute factored moment Mu (= 1.5× service moment).
  2. Fix b and D; take d = D − effective cover.
  3. Check Mu ≤ Mu,lim (0.138fckbd² for Fe415). If not, design as doubly-reinforced or increase depth.
  4. Find Ast from Mu = 0.87fyAstd[1 − Astfybd fck] (quadratic in Ast).
  5. Check Ast,min = 0.85bdfy and Ast,max = 0.04bD; detail the bars.

2.7 DOUBLY-REINFORCED BEAMS

Used when Mu > Mu,lim but the section size is restricted. The moment is split:

  • Balanced part: Mu,lim resisted by concrete + tension steel Ast1 = Mu,lim0.87fy(d − 0.42xu,max).
  • Extra part: Mu2 = Mu − Mu,lim resisted by compression steel Asc and extra tension steel Ast2:
    Asc = Mu2(fsc − 0.446fck)(d − d′);   Ast2 = Ascfsc − 0.446fck0.87fy.
  • Total Ast = Ast1 + Ast2. The compression-steel stress fsc depends on strain εsc = 0.0035(1 − d′xu,max) (from SP-16).
Example 2.3 — Doubly-reinforced design (from the manual)

b = 230, d = 500, d′ = 50 mm, factored wu = 55.44 kN/m over 5.5 m, M20, Fe415.

Mu = 55.44×5.5²8 = 209.65 kN-m; xu,max = 240 mm; Mu,lim = 0.36×20×230×240(500−100.8) = 158.66 kN-m < Mu ⇒ doubly-reinforced.

Ast1 = 158.66×1060.87×415×399.2 = 1100.8 mm²; Mu2 = 50.99 kN-m; Ast2 = 50.99×1060.87×415×450 = 313.8 mm² → Ast = 1414.6 mm² (5−20 mm).

εsc = 0.0035240−50240 = 0.00276 → fsc = 351.8 (SP-16); Asc = Mu2(fsc−8.92)(450) → compression bars.

2.8 FLANGED (T- AND L-) BEAMS

Effective flange width bf (IS 456): for a T-beam, bf = L06 + bw + 6Df; for an L-beam, bf = L012 + bw + 3Df (L0 = distance between points of zero moment; bw = web width; Df = flange depth).

Design cases:

  • NA within flange (xu ≤ Df): design as a rectangular beam of width bf — Mu = 0.87fyAst(d − 0.42xu).
  • NA in web (xu > Df): Mu = 0.36fckbwxu(d − 0.42xu) + 0.446fck(bf − bw)yf(d − yf2), where yf = min(Df, 0.15xu + 0.65Df).

2.9 SHEAR IN BEAMS

Nominal shear stress τv = Vub·d. Design shear strength of concrete τc depends on grade and the tension-steel percentage pt = 100Astbd (IS 456 Table 19). Maximum τc,max (Table 20) must not be exceeded.

  • If τv ≤ τc: provide only minimum stirrups — Asvb·sv = 0.40.87fy.
  • If τc < τv ≤ τc,max: design shear reinforcement for Vus = Vu − τcbd.
Vertical stirrups: Vus = 0.87fyAsvdsv ⇒ spacing sv = 0.87fyAsvdVus. Bent-up bars: Vus = 0.87fyAsv·sinα (α = 45° typically). Max spacing = 0.75d (vertical) and 300 mm.
Example 2.4 — Shear reinforcement design (from the manual)

bw = 250, d = 450 mm, Vu = 250 kN, M25, Fe415, τc = 0.668 Nmm².

τc,max(M25) = 3.1 > τv; Vus = Vu − τcbwd = 250000 − 0.668×250×450 = 174.87 kN.

2-legged 8 mm stirrups: Asv = 100.5 mm²; sv = 0.87×415×100.5×450174870 = 93.4 mm → provide 8 mm 2-legged @ 90 mm c/c (≤ 300 mm).

2.10 TORSION

Torsion is combined with bending and shear using equivalent actions (IS 456):

  • Equivalent shear: Ve = Vu + 1.6·Tub.
  • Equivalent moment: Me1 = Mu + Mt, where Mt = Tu(1 + Db1 + Db1.7. If Mt > Mu, provide compression-side steel for Me2 = Mt − Mu.
  • Longitudinal steel is designed for Me1; transverse (closed) stirrups for the torsional/shear demand.

2.11 BOND & DEVELOPMENT LENGTH

Development length
Ld = φ·σs4·τbd, where φ = bar diameter, σs = 0.87fy, τbd = design bond stress (increased 60% for deformed bars, 25% in compression).

Anchorage / flexural bond: at a simply supported end the code check is Ld ≤ 1.3·M1Vu + Lo, where M1 = moment of resistance of the bars continued, Vu = shear at support, Lo = anchorage beyond the support centre. Anchorage bond resists pull-out along the bar length; flexural (local) bond arises from the change of bar force due to the change of bending moment along the span.
